# Landing Page Copywriting

## Overview
Write compelling, conversion-focused copy for Focuspilot landing pages targeting interior designers and architects in the UK market.

## Brand Voice

### Tone
- **Calm & confident** - Not aggressive or salesy
- **Professional** - Sophisticated, not corporate
- **Empathetic** - Understands designer pain points
- **Clear** - Simple language, no jargon
- **Premium** - Quality feel, not discount messaging

### Language Guidelines
- Use British English spelling (colour, organise, centre)
- Say "interior designers" not "interior decorators"
- Say "studios" not "firms" or "companies"
- Avoid tech jargon - speak designer language
- Use "we" and "you" - conversational

### Words to Use
- Calm, serene, seamless
- Effortless, intuitive, streamlined
- Beautiful, elegant, refined
- Organised, connected, unified
- Purpose-built, designed for

### Words to Avoid
- Revolutionary, game-changing, disruptive
- Synergy, leverage, scalable
- Best-in-class, world-class
- Cutting-edge, state-of-the-art
- Cheap, discount, budget

## Copy Formulas

### Value Proposition Template
**Formula**: [Product] helps [audience] [achieve outcome] without [pain point]

**Example**: "Focuspilot helps interior design studios manage projects beautifully without the chaos of spreadsheets and scattered tools."

### Headline Formulas

**Problem-Agitate-Solve**
- Problem: "Tired of chasing procurement updates?"
- Agitate: "Every hour spent on admin is an hour away from design."
- Solve: "Focuspilot keeps everything in one calm place."

**Benefit-First**
- "Manage every project from enquiry to final install"
- "One workspace for your entire studio"
- "Beautiful project management for designers who care"

**Question Hook**
- "What if your project management felt as organised as your designs?"
- "Still managing FF&E in spreadsheets?"

### CTA Copy

**Primary CTAs (High commitment)**
- Start free trial
- Get started free
- Try Focuspilot free
- Start your free trial

**Secondary CTAs (Lower commitment)**
- Book a demo
- See it in action
- Watch 2-min demo
- Take a quick tour

**Tertiary CTAs (Information)**
- Learn more
- See features
- Compare plans
- Read customer stories

### Feature → Benefit Translation

| Feature | Benefit |
|---------|---------|
| Project timeline view | See every deadline at a glance |
| Automated reminders | Never miss a client approval |
| Client portal | Keep clients happy without endless emails |
| Procurement tracking | Know exactly where every item is |
| Invoice generation | Get paid faster with professional invoices |
| AI product extraction | Add products in seconds, not minutes |

## Page-Specific Copy Guidelines

### Homepage
- Hero: Single clear value prop + primary CTA
- Subhead: Expand on who it's for
- Social proof: Credibility immediately
- Features: Benefits-focused, not feature lists
- Final CTA: Repeat primary with urgency/reassurance

### Feature Pages
- H1: Benefit-focused, keyword-rich
- Opening: Pain point → solution flow
- Features: Show don't tell (screenshots)
- Proof: Customer quote or metric
- CTA: Relevant to this feature's value

### Pricing Page
- Clear tier names (not confusing)
- Highlight recommended plan
- Feature comparison that's scannable
- FAQ addressing pricing objections
- "No credit card required" reassurance

### Comparison Pages
- Honest, fair tone
- Clear winner statements where appropriate
- Focus on fit, not "better/worse"
- Acknowledge competitor strengths
- End with clear Focuspilot CTA

## Microcopy Guidelines

### Form Labels
- "Work email" not "Email address"
- "Studio name" not "Company"
- "Your name" not "Full name"

### Button States
- Default: "Start free trial"
- Loading: "Starting..."
- Success: "Welcome!"
- Error: "Please try again"

### Empty States
- Friendly, helpful tone
- Clear next action
- Example: "No projects yet. Create your first project to get started."

### Error Messages
- Apologetic but not groveling
- Explain what happened
- Offer clear next step
- Example: "We couldn't save that. Please check your connection and try again."

### Tooltips
- Brief (under 15 words)
- Helpful context
- No redundancy with labels

## Focuspilot-Specific Messaging

### Core Value Propositions
1. **All-in-one**: "Everything your studio needs in one calm workspace"
2. **Purpose-built**: "Designed specifically for interior designers"
3. **Beautiful**: "Project management that's as refined as your work"
4. **Connected**: "From first enquiry to final install, seamlessly connected"

### Key Differentiators to Emphasize
- Built specifically for interior design (not generic PM)
- UK-focused with British spelling and VAT support
- Modern, beautiful interface (not dated software)
- AI-powered features (procurement, proposals)
- Connects CRM → Projects → Procurement → Finance

### Pain Points to Address
- "Scattered across spreadsheets, email, and five different tools"
- "Spending more time on admin than design"
- "Chasing clients for approvals via email"
- "Lost track of that custom sofa order"
- "Invoice at the end, forgot to bill for changes"

## Instructions

1. **Before Writing**
   - Understand the page's goal
   - Identify target audience segment
   - Note where in the funnel (awareness → consideration → decision)
   - Review existing copy for context

2. **Writing Process**
   - Start with the benefit/outcome
   - Translate features to benefits
   - Keep sentences short (under 20 words)
   - One idea per paragraph
   - Read aloud to check flow

3. **Review Checklist**
   - [ ] Does it speak to interior designers specifically?
   - [ ] Is the benefit clear in the first line?
   - [ ] Is there a clear CTA?
   - [ ] Would a busy designer read this?
   - [ ] Is it British English?
   - [ ] Does it match brand voice?

4. **A/B Test Ideas**
   - Always have 2-3 headline options
   - Test CTA variations
   - Test short vs long descriptions
   - Document what works
