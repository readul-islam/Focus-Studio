# Conversion Rate Optimization (CRO)

## Overview
Optimize user journeys and conversion funnels through strategic design, compelling copy, and friction reduction to maximize signups and engagement.

## Key Conversion Elements

### Above-the-Fold Checklist
- [ ] Clear value proposition (what + for whom + benefit)
- [ ] Primary CTA visible without scrolling
- [ ] Supporting visual (product screenshot/demo)
- [ ] Trust signal (customer count, rating, logos)
- [ ] No competing CTAs diluting focus

### CTA Optimization
- [ ] Action-oriented verb ("Start", "Get", "Try")
- [ ] Specific outcome ("Start free trial" > "Sign up")
- [ ] Visual contrast (stands out from page)
- [ ] Appropriate size (44px+ touch target)
- [ ] Repeated strategically throughout page
- [ ] Low-commitment language ("No credit card")

### Trust & Social Proof
- [ ] Customer testimonials with photos/names
- [ ] Company logos (recognizable brands)
- [ ] Metrics ("500+ studios", "4.8/5 rating")
- [ ] Case studies or success stories
- [ ] Security badges where relevant
- [ ] Money-back guarantee or free trial messaging

### Form Optimization
- [ ] Minimal fields (email only for initial capture)
- [ ] Single-column layout
- [ ] Clear labels and placeholder text
- [ ] Inline validation with helpful errors
- [ ] Progress indicator for multi-step
- [ ] Privacy reassurance near submit

### Objection Handling
- [ ] FAQ section addressing concerns
- [ ] Comparison tables vs competitors
- [ ] Risk reversal (free trial, no lock-in)
- [ ] Clear pricing (no hidden costs)
- [ ] Support availability messaging

## Page-by-Page Analysis Framework

### Homepage
1. Can visitor understand offering in 5 seconds?
2. Is the primary CTA unmistakable?
3. Are benefits (not just features) highlighted?
4. Is there social proof visible early?
5. Does the page guide to a single action?

### Feature/Platform Pages
1. Does the H1 match search intent?
2. Are features tied to outcomes/benefits?
3. Is there a clear path to signup/demo?
4. Are screenshots showing real value?
5. Is pricing or next step clear?

### Pricing Page
1. Is the recommended plan highlighted?
2. Are plan differences easy to compare?
3. Is there a free option to reduce friction?
4. Are FAQs addressing pricing concerns?
5. Is the CTA on each plan clear?

## Copy Formulas

### Value Proposition Template
"[Product] helps [target audience] [achieve outcome] by [unique mechanism]"

Example: "Focuspilot helps interior designers manage projects effortlessly by connecting procurement, clients, and finances in one calm workspace"

### CTA Variations to Test
- Primary: "Start free trial" / "Get started free"
- Secondary: "Book a demo" / "See it in action"
- Tertiary: "Learn more" / "See how it works"

### Headline Formulas
- Problem-agitate-solve: Address pain, amplify it, present solution
- Benefit-focused: Lead with the outcome they want
- Question-based: "Tired of [pain point]?"

## Friction Points to Eliminate
- Required account creation before seeing value
- Complex multi-step forms
- Unclear pricing or hidden costs
- No way to contact support
- Slow page load times
- Confusing navigation
- Too many choices/options

## Metrics to Track
- Conversion rate (signups / visitors)
- Bounce rate per page
- Time on page
- Scroll depth
- CTA click-through rate
- Form abandonment rate
- Demo request rate

## Instructions

1. **Audit Current State**
   - Review homepage hero section
   - Map all CTAs and their destinations
   - Identify trust signals present
   - Check form complexity
   - Review objection handling

2. **Prioritize by Impact**
   - Focus on highest-traffic pages first
   - Start with above-the-fold improvements
   - Test primary CTA before secondary elements

3. **Implement Changes**
   - Make one change at a time when possible
   - Document baseline metrics
   - A/B test significant changes
   - Monitor for unintended consequences
